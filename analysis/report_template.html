Occlusion and key part

The occlusion number comes from the image filename. In the renders it looks like the visible share of the object rather than the covered share (rake_5 and whisk_5 show almost nothing), so read the x-axis with that in mind. The regression is a plain logistic model with no participant or object effects; with this few errors treat it as descriptive.

Does performance change during the test?

Trials grouped by position (1–7, 8–14, …). Participants who did the first, smaller version of the test only reach trial 21, so the later bins contain fewer people (see hover).

Reaction time in detail

Relative RT = each trial's time divided by that person's own median time, so 100 % is "their normal speed". This removes the difference between fast and slow people, which is larger than most effects here. Lines are 95 % bootstrap intervals of the median.
